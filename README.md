# Big Love Family - Wedding Invitation

A beautiful GitHub Pages website for wedding invitations.

## 🎉 About

This is a wedding invitation website built with HTML and CSS, hosted on GitHub Pages. The website features:

- Elegant and responsive design
- Wedding details (date, time, location)
- RSVP functionality
- Beautiful gradient color scheme
- Mobile-friendly layout

## 🚀 Live Demo

Visit the live website at: https://ntrieuvi97.github.io/biglovefamily/

## 📝 Customization

To customize the invitation for your wedding, edit the `index.html` file:

1. Update the couple's names
2. Change the date, time, and location
3. Modify the RSVP email address
4. Adjust colors and styling as needed

## 🛠️ Technologies Used

- HTML5
- CSS3
- GitHub Pages
