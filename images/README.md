# Đặt ảnh của bạn vào đây!

Thư mục này dùng để chứa các ảnh cho website wedding invitation.

## File ảnh đề xuất:

### Gallery (6 ảnh):
- `photo1.jpg` - Ảnh cặp đôi 1
- `photo2.jpg` - Ảnh cặp đôi 2  
- `photo3.jpg` - Ảnh cầu hôn/đính hôn
- `photo4.jpg` - Ảnh hẹn hò
- `photo5.jpg` - Ảnh du lịch
- `photo6.jpg` - Ảnh kỷ niệm

### Hero Background (tùy chọn):
- `hero-background.jpg` - Ảnh nền cho phần hero (1920x1080px)

## Lưu ý:
- Ảnh nên có kích thước: 1200x1200px (hoặc tỉ lệ vuông 1:1)
- Format: JPG hoặc PNG
- Kích thước file: Nên < 500KB mỗi ảnh để load nhanh

Copy ảnh vào đây, sau đó cập nhật `index.html` theo hướng dẫn trong file `HUONG_DAN_THEM_ANH.md`
